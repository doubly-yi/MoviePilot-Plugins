# MoviePilot-Plugins

Doubly 的 MoviePilot 第三方插件仓库，提供下载器种子管理和 bp PULSE 多账号签到插件。当前插件面向 **MoviePilot V2**。

## 插件一览

| 插件 | 当前版本 | 主要功能 | 适用环境 |
| --- | --- | --- | --- |
| [BT种子管理](#bt种子管理) | 0.0.2 | 添加种子标签、设置上传限速、分享率达到阈值时暂停做种 | MoviePilot V2、qBittorrent |
| [bp PULSE 签到](#bp-pulse-签到) | 1.0.1 | 多账号签到、短信登录、礼包领取、常用站点空闲枪数与优惠券汇总 | MoviePilot v2.15.6 及以上的 V2 版本 |

## 安装

1. 在 MoviePilot 的插件市场配置中添加本仓库地址：

   ```text
   https://github.com/doubly-yi/MoviePilot-Plugins
   ```

2. 刷新插件市场，搜索插件名称并安装。
3. 打开插件，按需配置并保存。

插件从仓库直接安装。bp PULSE 的界面文件已包含在仓库中，使用者无需安装 Node.js 或自行构建。

## BT种子管理

对选定 qBittorrent 下载器中符合筛选条件的种子进行管理：

- 批量添加自定义标签。
- 设置单个种子的上传速度上限。
- 在周期检查时，暂停分享率已达到设定阈值的种子。
- 支持 Cron 执行周期和“立即运行一次”。

### 使用方法

1. 启用插件，选择需要管理的下载器。
2. 填写标签名称，按需设置上传限速和分享率阈值。
3. 设置执行周期并保存；需要立即执行时，勾选“立即运行一次”。

当前按下载器返回的 tracker 数量为 `0` 筛选种子，这一条件不能准确区分所有 BT/PT 种子，使用前请确认符合自己的管理需求。分享率阈值由插件在执行时检查，达到阈值后暂停种子。

## bp PULSE 签到

管理多个 bp PULSE 账号，并独立完成登录和签到：

- 独立的签到看板和设置页，可查看各账号的登录状态与最近签到结果。
- 支持添加、编辑和删除多个账号，分别设置是否参与定时签到。
- 手动点击账号“登录”发送短信验证码，验证成功后自动保存登录信息。
- 支持单账号手动签到、Cron 定时签到和礼包领取。
- 同一轮定时签到的多账号结果合并为一条通知，包含失败结果和本轮登录过期提醒。
- 每个账号可独立关闭签到后自动领奖，默认开启；支持手动领取所选账号全部已达标的签到奖励。
- 查看每个账号的奖励任务、进度及接口返回状态；明确待领取时显示数量，查看详情不触发签到或领奖。
- 登录过期时发送通知，由用户手动重新登录，不会自动发送验证码。
- 搜索并设置常用充电站，查看空闲枪数、总枪数和最大功率。
- 汇总各账号的本站适用券，展示门槛、有效期和使用规则，标记 3 天内到期的券；也可查看全部未使用券。

### 使用方法

1. 打开插件，进入“设置”，添加账号名称和手机号。
2. 点击“查看数据”返回看板，为对应账号完成短信登录。
3. 点击“签到”手动执行，或在设置中启用定时签到、填写 Cron 并保存。
4. 在 MoviePilot 中配置通知渠道，并允许“插件”类型通知，以接收登录过期提醒。
5. 在设置中搜索并保存常用充电站，在看板比较各账号的适用券。打开看板时自动查询，也可手动刷新；成功结果在 60 秒内复用。

账号和登录信息即时保存；常用站点、执行周期、定时签到开关及通知选项需要在设置页点击“保存”。默认执行周期为 `0 8 * * *`，即按 MoviePilot 时区每天 08:00 执行。查询优惠券不触发签到或领奖，也不需要开启定时签到。

更多账号设置、通知规则和常见问题见 [bp PULSE 使用说明](plugins.v2/bppulsesignin/README.md)。
