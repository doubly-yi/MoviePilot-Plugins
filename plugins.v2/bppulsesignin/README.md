# bp PULSE 签到

当前版本：**1.0.1**。适用于 MoviePilot V2 的多账号签到插件，支持短信验证码登录、单账号手动签到、定时签到、礼包领取，以及常用站点优惠券汇总。

## 安装要求

需要 MoviePilot **v2.15.6 或更高的 V2 版本**，不支持 V3。

在 MoviePilot 的插件市场配置中添加[本仓库地址](https://github.com/doubly-yi/MoviePilot-Plugins)，刷新插件市场并安装“bp PULSE 签到”。插件直接从仓库安装，已包含界面所需的构建文件，无需额外构建。

手动安装时，请完整复制插件目录中的 `__init__.py`、`client.py`、`coupons.py` 和 `dist/`，缺少 Python 文件或 `dist/` 会导致插件或页面无法加载。

使用 MoviePilot 的“本地插件仓库路径”时，该路径必须指向包含索引的仓库根目录，目录结构如下：

```text
本地仓库目录/
├── package.v2.json
└── plugins.v2/
    └── bppulsesignin/
        ├── __init__.py
        ├── client.py
        ├── coupons.py
        └── dist/
            └── assets/
```

配置路径后，刷新插件市场并安装本地来源的插件。

## 添加账号与登录

1. 打开插件，默认进入签到看板，点击右下角“设置”进入配置页。
2. 点击“添加账号”，填写账号名称和手机号。Token 可以留空；已有 Token 时也可以直接填入。
3. 保存账号后，点击“查看数据”返回看板。
4. 点击对应账号的“登录”，插件会向该账号的手机号发送短信验证码。
5. 输入收到的验证码，点击“验证并登录”。验证成功后自动保存登录信息。

支持添加多个账号，各账号的登录信息和签到状态独立保存。账号新增、编辑和删除会即时保存。

## 手动签到与定时签到

在看板点击账号对应的“签到”，即可为该账号单独签到，无需开启定时签到。

需要自动执行时，在设置页开启“启用定时签到”，填写执行周期并点击底部“保存”。只有勾选“参与定时签到”的账号会自动执行。

执行周期使用五段 Cron 表达式，按 MoviePilot 配置的时区执行：

| Cron 表达式 | 执行时间 |
| --- | --- |
| `0 8 * * *` | 每天 08:00（默认） |
| `30 9 * * *` | 每天 09:30 |
| `0 8,20 * * *` | 每天 08:00 和 20:00 |

保存后，可在 MoviePilot 的服务列表查看“bp PULSE 多账号签到”。

默认签到后会尝试领取全部已达标的礼包。如果礼包领取失败，看板会保留已签到的结果，下次执行时再次尝试领取。

### 按账号控制领奖

在“设置 → 账号管理 → 编辑”中，通过“签到后自动领取奖励”开关控制该账号的领奖行为。新增及已有账号默认开启，保持原来的签到流程；关闭后，手动签到和定时签到都不再主动调用领奖。点击“保存账号”立即生效，不影响其他账号。

需要单独测试延后领奖时，只为测试账号关闭此开关，并保持“参与定时签到”开启。到达奖励条件后，先查看 bp 中的奖励状态；未领取奖励的保留期限、有效期起算规则仍需验证，不能保证延后领取一定能延长有效期。

看板每个账号旁的“领取全部奖励”会领取该账号当前所有已达标且尚未领取的签到奖励，不触发签到，也不改变自动领奖或定时签到开关。手动领奖结果单独显示，查询成功后会刷新优惠券。无待领奖励时会提示“暂无可领取礼包”。

当前仅对接已确认的全部领奖接口，暂不提供单项领奖。该按钮不会自动领取尚未达标的奖励，也不用于领取其他活动的赠券。

### 查看奖励任务

每个账号的签到结果下方提供“奖励详情”，可查看奖励名称、任务进度和 bp 返回的状态。只有接口状态文字明确为“待领取”或“可领取”时，入口才显示“待领取 N 项”；不会仅因进度达标或某个未验证的状态码就判定可以领奖。没有状态文字时显示“状态未说明”及原始状态码。

打开看板、点击顶部“刷新”或详情中的“刷新奖励”会只读查询任务，同一分钟内复用成功结果。签到和手动领奖后会重新查询。查询失败时保留上次结果并显示错误及更新时间，不将失败当成没有待领奖励。查看详情不会触发签到或领奖。

## 登录过期与通知

登录失效时，账号会显示“已过期”，并发送一次通知提醒。插件不会自动发送验证码或重新登录；请在看板点击该账号的“登录”，重新完成短信验证。

需要在 MoviePilot 中配置通知渠道，并允许接收“插件”类型的通知。“发送签到结果通知”控制普通签到结果通知，关闭后仍会发送登录过期提醒。

同一轮定时签到结束后，所有参与账号的结果合并为一条通知，逐个列出账号名称和签到结果；失败不会影响其他账号。定时签到中发现的登录过期提醒也合并发送，不再为每个账号单独推送。关闭结果通知时，只汇总尚未提醒过的登录失效账号；提醒发送失败会留待后续重试。单账号手动签到仍单独通知。

## 常用充电站与优惠券

1. 先为至少一个账号完成登录，进入设置页的“常用充电站”，点击“选择站点”。
2. 输入至少两个字符的站名关键词，点击“搜索”。可分页查看结果，按名称和地址确认站点。
3. 选择结果后，点击设置页底部“保存”。所有账号共用这个常用站点，也可更换或清除。
4. 返回看板，顶部可查看本站适用券数量；签到状态下方展示常用站点的空闲枪数、总枪数、最大功率，以及各账号的优惠券。

看板会在打开时查询站点及已登录账号的未使用券，也可点击“刷新站点与优惠券”。同一份成功结果在 60 秒内复用，不需要开启定时签到。空闲枪数显示的是查询当时的数据，并附有更新时间；出发前请刷新确认。

优惠券包括接口返回的官方赠券和签到奖励券，展示折扣或抵扣金额、订单门槛、有效期及使用规则。默认显示本站适用券，按到期时间排序，3 天内到期的券会醒目标记。切换“全部未使用券”可查看其他站点的券。当前仅提供页面临期标记，不发送优惠券临期通知。

“本站适用”表示该站点出现在已确认的券适用范围内；订单金额、每日时段、会员或星期限制仍需满足，以实际结算为准。空站点列表和未确认的范围类型会显示“站点范围待确认”，不会当作全站通用券。缓存中已过期或尚未生效的券会标注状态。

查询失败时显示失败原因，并保留上次结果和时间，不将查询失败当成“没有优惠券”。账号登录过期仍只通知，由用户手动重新登录。优惠券查询不会触发签到或领取奖励。

## 常见问题

- **编辑账号时需要重新填写 Token 吗？** 不需要，留空会保留原有登录信息。更换手机号会清除旧登录信息，也可以勾选“清除已保存的登录信息”。
- **为什么账号显示“待验证”？** 手动填入的 Token 需要通过签到或优惠券查询确认是否有效，查询成功后会显示“已登录”。
- **多久可以重新发送验证码？** 重发间隔为 60 秒。请在打开登录窗口后的 10 分钟内完成验证；短信本身的有效期以 bp 服务为准。
- **一个账号失败会影响其他账号吗？** 不会，定时签到会继续处理其他账号。
- **设置修改后为什么没有生效？** 账号操作即时保存；常用站点、执行周期、定时签到开关和通知选项需要点击设置页底部的“保存”。
- **替换本地插件文件后，界面仍是旧的怎么办？** 替换完整的 `dist/`，关闭插件弹窗并强制刷新整个 MoviePilot 网页，再重新打开插件。
- **热加载后提示“插件已停止或重载”怎么办？** 当前核对的 MoviePilot V2.15.6 在文件热加载后可能仍保留旧的 API 绑定。进入插件设置，保持原有配置并点击“保存”，然后重试。
- **在哪里查看运行日志？** 在 MoviePilot 插件菜单中打开日志，可查看初始化、签到开始、执行结果和失败原因；日志不包含登录凭据。
